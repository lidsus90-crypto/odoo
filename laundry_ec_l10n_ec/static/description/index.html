Laundry EC — Localización Ecuador

Módulo puente que activa la integración entre el sistema de lavandería y la facturación electrónica SRI.
Desarrollado por LeadSolutions Cia. Ltda. para Odoo 18.

¿Qué hace este módulo?

Este es un módulo puente (glue module). No contiene modelos ni vistas propios. Su único propósito es declarar la dependencia conjunta entre Laundry Management y l10n_ec_edi, permitiendo que Odoo active automáticamente la integración con la facturación electrónica del SRI cuando ambos módulos están instalados en la instancia.

Instalación automática

El módulo tiene auto_install: True. Odoo lo activa de forma automática cuando detecta que los siguientes módulos están instalados simultáneamente:

laundry_management Sistema de gestión de órdenes de lavandería (LeadSolutions)
l10n_ec_edi Localización ecuatoriana — facturación electrónica SRI (Odoo / OCA)

Comportamiento por región

Escenario Resultado
Instancia Ecuador con l10n_ec_edi instalado ✔ Se instala automáticamente
Instancia fuera de Ecuador (sin l10n_ec_edi) ✗ No se instala (no aplica)
