Laundry Configuration

Base configuration module for the laundry management platform.
Provides catalogs, washing methods and product categories required for core operations.
Developed by LeadSolutions Cia. Ltda. for Odoo 18.

Included Configuration

This module provides the required configuration data for the laundry management system:

  • Claim Catalog - Available service claim types
  • Washing Methods - Configurable washing methods
  • Method Types - Classification of methods such as manual or automatic
  • Product Categories - Classification of garments and products
  • Product Templates - Base products for service orders
  • Access Control - User permissions and roles for the system

Features

  • Preloaded configuration data for laundry operations
  • Reusable modular structure
  • Ecuador localization support
  • Compatible with Odoo 18.0

Note: This module is a base dependency. It is recommended to install Laundry Setup that automatically includes this module and the full laundry management functionality.
