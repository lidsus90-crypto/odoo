Laundry Configuration

Módulo de configuración base para el sistema de gestión de lavandería.
Proporciona catálogos, métodos y categorías de productos necesarios para el funcionamiento del sistema.
Desarrollado por LeadSolutions Cia. Ltda. para Odoo 18.

Configuración Incluida

Este módulo proporciona la base de datos de configuración necesaria para la operación del sistema:

  • Catálogo de Reclamos - Tipos de reclamos disponibles en el sistema
  • Catálogo de Métodos de Lavado - Métodos de lavado configurables
  • Tipos de Métodos de Lavado - Clasificación de métodos (manual, automático, etc.)
  • Categorías de Productos - Categorización de prendas y productos
  • Plantillas de Productos - Productos base para órdenes de servicio
  • Control de Acceso - Permisos y roles para usuarios del sistema

Características

  • Datos precargados en español
  • Estructura modular y reutilizable
  • Localización para Ecuador
  • Compatible con Odoo 18.0

Nota: Este módulo es una dependencia base. Se recomienda instalar Laundry — Sistema de Gestión de Lavandería que incluye automáticamente este módulo junto con todas las funcionalidades del sistema.
