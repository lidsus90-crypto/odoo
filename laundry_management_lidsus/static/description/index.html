Laundry Management — Sistema de Gestión de Órdenes

Módulo de gestión completa para órdenes de servicio de lavandería con flujo de estados, guías de entrega/despacho, reclamos y facturación integrada.
Desarrollado por LeadSolutions Cia. Ltda. para Odoo 18.

Órdenes de Servicio

Registro completo de órdenes de servicio con control de prendas por tipo, color, método de lavado y cantidad. Secuencial automático por compañía.

  • Flujo de 7 estados: Recibido → Enviado → En Proceso → En Tránsito → Listo → Entregado / Reclamo
  • Campos bloqueados automáticamente en estados distintos a Recibido
  • Generación de factura de venta desde la propia orden
  • Dirección de entrega seleccionable entre todas las ubicaciones del cliente
  • Vistas: formulario, lista, kanban, pivot y gráfico

Guías de Entrega y Despacho

Generación automática de guías de entrega (cliente) y despacho (interno) con reportes impresos y trazabilidad completa del movimiento de prendas.

  • Guía de Entrega - Documento para cliente con detalle de prendas
  • Guía de Despacho - Documento interno con instrucciones de lavado
  • Secuencial automático por serie y compañía
  • Reportes impresos personalizados
  • Confirmación de recepción de guías

Gestión de Reclamos

Registro y seguimiento de reclamos por prendas dañadas, perdidas o con defectos, vinculados directamente a órdenes de servicio.

  • Tipos de reclamo configurables
  • Líneas de detalle por prenda reclamada
  • Flujo de estados para seguimiento
  • Vinculación automática con órdenes de servicio

Análisis y Reportes

  • Vistas Pivot: análisis cruzado por cliente, estado, planta
  • Gráficos de barras y análisis de tendencias
  • Totales facturados y prendas procesadas
  • Exportable a Excel

Nota: Este módulo requiere Laundry Configuration como dependencia base. Se recomienda instalar Laundry — Sistema de Gestión de Lavandería (Setup) que incluye automáticamente este módulo con toda la configuración completa.
