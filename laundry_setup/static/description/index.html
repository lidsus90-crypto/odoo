Laundry Setup

Installer module for the complete Ecuadorian laundry management system on Odoo 18.
Includes configuration, management workflows and setup data required for the laundry application.
Developed by LeadSolutions Cia. Ltda..

Service Orders

Complete service order management with garment tracking by type, color, washing method, and quantity. Automatic company sequence numbering.

  • 7-step workflow: Received → Sent → In Process → In Transit → Ready → Delivered / Claim
  • Automatic field locking outside the Received state
  • Invoice creation from the service order
  • Delivery address selection from customer locations
  • Form, list, kanban, pivot and graph views

Dashboard and Kanban

Order dashboard with kanban grouped by stage, pending activities indicators, and invoice status badges on each card.

  • Kanban grouped by order workflow stage
  • Progress bars by column for today / overdue / planned activities
  • Invoice status badge visible on each card
  • Activity logging: calls, tasks, emails, meetings
  • Available in Orders, Claims, Delivery Guides and Dispatch Guides

Reporting and Analytics

Pivot and graph views for cross-analysis of orders, claims, and guides by customer, state, plant, and totals.

  • Pivot views with customer and state dimensions
  • Configurable measures for invoiced totals and garment quantities
  • Stacked bar charts by order state
  • Garment processing analysis by plant
  • Excel export from the Odoo interface

Delivery Guides

Customer delivery guide tracking with full lifecycle traceability and automatic dispatch guide creation.

  • Automatic dispatch guide generation on shipment confirmation
  • Partial or full garment receipt control
  • Field locking outside draft state
  • Direct linkage to orders and claims
  • Kanban, pivot and graph views by plant and state

Note: This module installs the full laundry management workflow and is intended to be used with Laundry Configuration as a base dependency.

Guías de Despacho

Seguimiento del despacho de prendas hacia la planta de lavado. Generada automáticamente desde la Guía de Entrega al confirmar el envío.

  • Creación automática al validar la Guía de Entrega
  • Control de recepción en planta: total o parcial
  • Al marcar como Recibido actualiza automáticamente la orden a Entregado
  • Campos bloqueados en estados distintos a Borrador
  • Vistas kanban, pivot y gráfico incluidas

Flujo de trabajo

Recibido Se registra la orden con las prendas del cliente y la dirección de entrega
Enviado Se genera la guía de entrega y automáticamente la guía de despacho hacia la planta
En Proceso La planta confirma recepción y procesa el lavado
En Tránsito Las prendas regresan al punto de entrega
Listo Prendas disponibles para entrega al cliente
Entregado Orden cerrada automáticamente cuando ambas guías están en estado Recibido
Reclamo Gestión de inconformidades con seguimiento dedicado, actividades y resolución

Módulos incluidos

laundry_configuration Catálogos base: métodos de lavado, tipos, categorías de producto
laundry_management Órdenes de servicio, guías de despacho/entrega, reclamos y facturación
laundry_setup Instalador global que unifica los módulos en una sola instalación
laundry_ec_l10n_ec Puente con la localización ecuatoriana (l10n_ec_edi). Se instala automáticamente cuando ambos módulos están presentes.
